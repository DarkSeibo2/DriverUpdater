# Driver Updater

Портативная Windows-утилита (WPF, .NET 8): сканирует устройства, находит обновления
драйверов сразу в 10 источниках, делает бэкап перед установкой и ставит обновления.

Запускается без установки: single-file exe рядом с собой хранит настройки и данные
(`Data/`). Для работы требует запуска от администратора (манифест уже настроен).

## Возможности

- Сканирование PnP-устройств и оценка состояния драйверов
- Поиск обновлений в 10 источниках (см. ниже), включая анонсы для устройств
  без установленного драйвера (driverless: AMD PSP/GPIO и другие платформенные устройства)
- Резервное копирование драйверов перед установкой
- Установка обновлений с флагом «требуется перезагрузка» (pnputil)
- Проверка файлов: подпись Authenticode, издатель и контрольные суммы
- Переносимые настройки рядом с exe, атомарное сохранение, ротация логов

## Источники обновлений

| Источник | Что ищет |
|---|---|
| Microsoft Catalog | Microsoft Update Catalog |
| Windows Update | драйверы через клиент Windows Update |
| Windows Update Full | расширенный проход Windows Update (в т.ч. driverless-устройства) |
| Winget | обновления программ через winget |
| Chocolatey | обновления программ через choco |
| SDI | пакеты Snappy Driver Installer |
| DriverPack | пакеты DriverPack |
| Vendor | сайты вендоров |
| NVIDIA GeForce | драйверы NVIDIA |
| Lenovo | дескрипторы/каталог Lenovo (HWID, даты сборок) |

## Скачивание готовой версии

GitHub Actions при каждом пуше в `main` автоматически собирает portable-версию,
прогоняет тесты и публикует zip-архив во вкладке **Releases**
(`DriverUpdater-portable-build-N.zip`) вместе с файлом контрольной суммы
`.sha256` — скачанный архив можно сверить до запуска. Достаточно распаковать
архив в любую папку и запустить `DriverUpdater.exe` — установщик не нужен.

## Безопасность

Программа запускается с правами администратора и исполняет скачанные пакеты,
поэтому перед запуском любого файла работает общий «шлюз» проверки:

1. скачивание — только HTTPS и только с разрешённых доменов (после редиректов
   тоже), жёсткий лимит размера, idle-таймаут на приём данных, недокачанные
   файлы удаляются;
2. контрольная сумма пакета, если источник её публикует (Lenovo SHA-1, и т.п.);
3. подпись Authenticode + сверка издателя с известным списком по границам слов
   (NVIDIA → NVIDIA, Lenovo → Lenovo, Vendor-сайты → Intel/AMD/NVIDIA/Realtek
   по хосту; неизвестные хосты не запускаются вовсе); при желании включается
   проверка отзыва сертификатов (CRL/OCSP);
4. ZIP-пакеты распаковываются с защитой от Zip Slip и лимитами
   (размер распаковки, число файлов); вендорские zip ставятся не запуском
   содержимого, а через pnputil по INF;
5. перед установкой через pnputil подписи всех `.cat`-каталогов пакета
   проверяются по политике драйверов (WinVerifyTrust, DRIVER_ACTION_VERIFY),
   а каждый INF/SYS должен реально входить в один из этих каталогов — подпись
   постороннего `.cat` без нужных хешей не проходит;
6. для Lenovo проверяется подпись `dpinst.exe` (Microsoft/Lenovo), дерево
   распакованного пакета ограничивается по размеру и числу файлов;
7. Microsoft Catalog принимает только `.cab`/`.zip` — `.exe`/`.msu` не
   исполняются в обход INF/`.cat`-проверки;
8. все внешние процессы убиваются целым деревом по таймауту или отмене;
   захваченный вывод ограничен по размеру, бэкап/восстановление драйверов
   имеют собственные таймауты.

## Сборка

```
dotnet build DriverUpdater.sln
```

Публикация portable-версии (single-file, self-contained):

```
dotnet publish DriverUpdater/DriverUpdater.csproj -c Release -r win-x64
```

CI берёт версию из `DriverUpdater.csproj`, действия GitHub Actions закреплены
по commit SHA, а обновления NuGet-пакетов и actions приходят через Dependabot
(`.github/dependabot.yml`).

## Тесты

xUnit, 205 тестов (парсеры NVIDIA/Lenovo, сопоставление версий, проверка файлов
и подписей, границы издателя, привязка `.cat` к INF/SYS, шлюз установки,
host-allowlist, безопасные temp-каталоги, Zip Slip и лимиты распаковки,
лимиты/редиректы/idle-таймаут загрузки, лимиты вывода и таймауты процессов,
конвертеры WPF, настройки, DI-обвязка источников):

```
dotnet test DriverUpdater.sln
```
